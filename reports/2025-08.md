## Findings (using H1)

- Kiwix Hotspot H1 is well capable of handling the 24 users it can offer WiFi slots for.
- The 24 WiFi slots limit is a hard limit.
- That 24 slots can quite easily become 23 slots due to unsolicited people around. Exact condition hasn't been determined but it happens only when there are surrounding people. Must be noted that it's unclear if environment disturbs the Hotspot or the testbench (or both).
- Surrounding people (depends on environment) are likely to connect. Using an Open network should be reserved for Open scenarios.
- There is no indication anywhere that an hotspot has reached its WiFi capacity.
- When limit is reached, new users simply fail to connect, without explanation. Can be confusing for those previously connected.
- Download speeds are tolerable at best (single user) and painful in many-downloads scenarios. This is because any decent client has more capacity than the total WiFi bandwidth so any multiple-user scenario means dividing existing bandwidth.
- Video bitrate used in youtube2zim is low-enough for video usage to not be a concern.
- Hotspot would not support youtube2zim switching to 4K quality (not envisioned at all though).
- With this number of users, on such a high-end device, kiwix-serve performs well.
- When there is no breathing time between requests (`basic-http` – unrealistic), the Hotspot can't keep up and has to drop some.
- It's possible to get the Hotspot to a weird state where it's apparently working (some clients work OK) but slots gets very limited and network is unstable (mostly read timeouts). It's unclear if it was caused by the testbench. Only remedy was power-off.

## performances

### Basic HTTP browsing

Here we specifically asking JMeter to query all resources of random pages (in the hundred) but we are not actually downloading them so if there's 100 resources, it looks like 100 requests coming not concurrently but kind of as a batch.

```sh
❯ uv run testbench --exclude-broadcom --max-devices 24 jmeter --passphrase renaud-only --ssid testbench
```

```

+--------+---------+---------+--------------+
| Total  |   2703  |    57   |    97.93%    |
+--------+---------+---------+--------------+
```

Hotspot can handle two of such *users* but then it's too much requests and some are dropped.

> [!NOTE]
> Errors in this case are network errors on resources (`Socket closed` or `Request execution failed`)
> 
> Test ZIM's homepage usually contains 100+ resources.
